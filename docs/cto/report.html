Landing page v2 and README: delivery report

Done. cto-team now has two landing pages, one in English and one in Vietnamese, with the same design and a switch between them. It also has two matching READMEs and a test file that keeps all four in line. Every check passed. Nothing was pushed, merged or deployed. The work is on branch cto/2026-10-18-landing-v2 and waits for you.

How to try it

In a terminal, go to the worktree folder .claude/worktrees/cto-landing-v2 (or check out the branch) and run:

python -m http.server 8080 --directory docs

Then open http://localhost:8080/ (English) and click VI for the Vietnamese page. Try it on your phone's width, in dark mode, and press Pause / Next on the gate diagram.

Read README.md and README.vi.md on the branch. GitHub shows the gate diagram once the branch is pushed.

Run the tests: npm test (100 tests, all pass).

To go live on Cloudflare Pages, publish only docs/index.html and docs/vi/ (see the gaps below).

What works

1. Two landing pages, English and Vietnamese, with a switch. Done: docs/index.html and docs/vi/index.html. An EN | VI switch sits in the header, and hreflang tags tell Google the two pages are translations of each other. Checked by: a browser test that clicked the switch both ways and read the page head.

2. Short page, benefits first. Each page has a short hero with the install command and a Copy button, then an animated diagram of one gate (workers, then verifier, then fixer, then pass) that you can pause and step through. Then come ten feature cards (before, after, benefit), "Start in 3 steps" with the real commands, and a footer. It has no benchmark charts and no long tables. Checked by: a browser at 320 and 375 px (no sideways scrolling), light and dark mode, and reduced motion. A separate "first-time visitor" tester also used the pages.

3. READMEs in both languages. README.md (88 lines) and README.vi.md (77 lines) follow the same order. Each has a hero line, install, a feature table (before / after), a small gate diagram, 3 steps, FAQ and credits. Each links to the other language and to the landing page. Checked by: an Opus review and the new tests.

4. Good SEO. Each language has its own title, description, Open Graph tags (for link previews on social media), one main heading, and feature names as headings. Each page also has JSON-LD, a small block that tells search engines "this is a free developer app". Checked by: the final verifier and tests/docs.test.mjs.

Extra safety: tests/docs.test.mjs fails if the install lines, the version, the ten feature names, the language links or the banned "SDD missed…" claim ever drift.

Known gaps and tech debt

Before you deploy: if Cloudflare Pages publishes the whole docs/ folder, it also publishes the internal notes next to the pages (docs/cto/, specs, plans). They are already public in the GitHub repo and hold no secrets, but they do not belong on the site. Set the Pages output to a folder that holds only index.html and vi/, or add a small copy step. There is also no robots.txt or sitemap.xml yet. Each takes a few minutes.

Small items, none of them blocks use:

  • The browser tab has no icon, so it logs one harmless "favicon not found" message. Fix: one line.
  • Screen readers hear the diagram caption every 2.2 seconds while it plays, until the user presses Pause. Fix: small.
  • Vietnamese wording: the page's proof point 5 says "số 20 chữ số" (it leaves out "tiền", money). Proof point 7 keeps an English phrase. Fix: two words.
  • README.vi.md is shorter than the English one in the settings notes, and its diagram has no "pass/fail" labels. Fix: small.
  • The tests do not yet catch every drift, for example small wording differences between EN and VI, or a suffix added to an install line. Fix: small.
  • In the check sandbox, Google Fonts could not load, so nobody saw the Vietnamese letters in the real fonts. The fonts do support Vietnamese. Check once in your browser.

Full list: docs/cto/techdebt.md.
