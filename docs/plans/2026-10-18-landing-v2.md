# cto-team landing page v2 (EN + VI) and README — Implementation Plan

**Goal:** Benefit-first landing pages in English and Vietnamese plus matching READMEs, for SEO and marketing.
**Spec:** docs/specs/2026-10-18-landing-v2.md (its Features table, Anti-goals and Constraints are binding)
**Tech:** self-contained HTML (inline CSS/JS, Google Fonts only), Markdown + Mermaid, Node test runner.

## Global Constraints
- Content only from the spec's Features table. No benchmark charts or long comparison tables. No banned claims.
- Feature names, exactly (English / Vietnamese), in this order:
  1. "CTO plans once, then delivers gate by gate" / "CTO lên plan một lần, giao việc theo từng gate"
  2. "Contract-first API" / "Contract-first API"
  3. "The CTO splits the team" / "CTO tự chia team"
  4. "Blind verifier on every gate" / "Verifier độc lập ở mọi gate"
  5. "No fake tests, no 500s" / "Không test giả, không lỗi 500"
  6. "Opus batch review" / "Opus review theo đợt"
  7. "Lean on tokens" / "Tiết kiệm token"
  8. "ripgrep instead of grep" / "ripgrep thay cho grep"
  9. "Picks up after a reset" / "Làm tiếp sau khi reset"
  10. "Report a non-coder can read" / "Báo cáo người không code cũng đọc được"
- Install lines exactly: `/plugin marketplace add nhattrung0911/cto-team` and `/plugin install cto-team@cto-team`.
- Version 0.4.0. Landing URL https://cto-team-skill.pages.dev/ (EN) and https://cto-team-skill.pages.dev/vi/ (VI).
- No new dependencies. Do not touch skills/, agents/, hooks/, .claude-plugin/.
- Test command: `npm test` (must stay green).

### Task 1: Landing pages EN + VI
**Files:** Create `docs/index.html`, `docs/vi/index.html`; Delete `docs/landing-draft.html`.
**Interfaces:** Produces: each page has `<html lang="en">` / `<html lang="vi">`, `<link rel="alternate"
hreflang="en" href="https://cto-team-skill.pages.dev/">` and `hreflang="vi" … /vi/`, a visible language switch
linking `/` ↔ `/vi/`, an element `#installCmd` with the two install lines, one `<h2>` or `<h3>` per feature with
the exact feature name, and a `prefers-reduced-motion` rule.
**Steps:** Start from the draft's visual system (tokens, fonts, blueprint grid), not its sections. Build:
hero (name, one-line promise, install + copy button, GitHub link, language switch) → short animated gate diagram
(workers → verifier → fixer → pass, with Pause and Next) → ten feature cards (name, Before line, After line,
benefit, optional proof point) → "Start in 3 steps" → footer (MIT, credit obra/superpowers, repo link). SEO head:
title, meta description, canonical, Open Graph, JSON-LD `SoftwareApplication` (name, description,
applicationCategory DeveloperApplication, operatingSystem Windows/macOS/Linux, offers price 0, url, license MIT).
The Vietnamese page is a faithful translation in natural Vietnamese (keep gate, worker, verifier, test, token,
contract in English).
**Acceptance criteria:**
1. [Important] Both pages are complete valid documents and open with no console errors — check: Playwright, read
   the console for each page.
2. [Important] Ten feature names exactly as in Global Constraints, in order, on each page; every Before/After and
   proof point matches the spec's Features table; EN and VI say the same things — check: read both pages.
3. [Important] Language switch works both ways and `hreflang` alternates are present — check: click the switch in
   Playwright, and read the head.
4. [Important] At 375px: no horizontal page scroll on either page (`scrollWidth <= 375`), cards stack to one
   column — check: Playwright at 375px.
5. [Important] WCAG AA contrast in light and dark themes, no body text under 12px, no thick one-sided card
   borders, uppercase only on short labels, ≥12px padding in bordered boxes — check: computed styles in the browser.
6. [Important] The diagram animates, can be paused and stepped with keyboard and mouse, and shows a static final
   state under `prefers-reduced-motion: reduce` — check: Playwright with reduced-motion emulation.
7. [Minor] No benchmark charts or comparison tables remain from the draft.
**Break-prone cases:** dark theme by `prefers-color-scheme` and by `data-theme`; clipboard refused (copy falls
back to selecting the text); 320px width; Vietnamese diacritics render in the chosen fonts (pick fonts with
Vietnamese subsets; IBM Plex Sans and Bricolage Grotesque support Vietnamese — verify, else fall back).
**Commands:** full suite `npm test`. Open a page: Playwright on `file:///<project>/docs/index.html`.
**Out of scope:** READMEs, tests.

**Files:** Create or replace `tests/docs.test.mjs`.
**Interfaces:** Consumes Tasks 1–3 outputs and `.claude-plugin/plugin.json`.
**Steps:** `node:test` + `node:assert/strict`, `fs` only. Tests:

2. `plugin.json` version appears in both pages and both READMEs.
3. The ten English feature names appear, in order, in `docs/index.html` and `README.md`; the ten Vietnamese names,
   in order, in `docs/vi/index.html` and `README.vi.md`.
4. Pages: `lang` attribute correct, both `hreflang` alternates, a link to the other language, `#installCmd`,
   `prefers-reduced-motion`, JSON-LD script with `"SoftwareApplication"`; `docs/landing-draft.html` is gone.

6. No file contains "SDD" in the same sentence as "miss" (banned claim).
Each test must fail when its condition is broken.
**Acceptance criteria:** 1. [Important] Tests exist, pass, and each can fail. 2. [Important] `npm test` green.
**Commands:** `node --test tests/docs.test.mjs`; full suite `npm test`.
